## Findings and limits

- Current linked branch page is Matina, not Mintal. Earlier prototype branch text needs correction when implementation resumes.
- Gensan and Matina galleries contain treatment results, promotional graphics, and people photographs. Digos gallery contains many treatment comparisons and branded promotional graphics.
- No clean, standalone reception photo was shortlisted in this pass. A building image appeared inside a Digos promotional graphic; that is not a substitute for an original branch interior photograph.
- Facebook required login during deeper Digos browsing, so this is a focused shortlist rather than an exhaustive archive review.
- Use the clinic's original full-resolution files for presentation/publication where available. Confirm use of campaign and patient images with the clinic before publishing.
